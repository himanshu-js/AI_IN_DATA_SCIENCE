# AI_IN_DATA_SCIENCE 🚀

Welcome to the **AI in Data Science** repository! This project serves as a comprehensive collection of code, notes, and implementations focused on mastering Artificial Intelligence and Data Science using Python. 

## 🎯 Repository Goals
This repository is designed to document the step-by-step progression from foundational Python programming to building, evaluating, and deploying Machine Learning models.

## 🗂️ Learning Path & Contents

### 1. Python for Data Science
* Core Python concepts (Variables, Loops, Functions, OOP)
* Data Structures (Lists, Dictionaries, Tuples, Sets)
* Functional programming and list comprehensions

### 2. Data Manipulation & Analysis
* **Pandas:** Series, DataFrames, data cleaning, boolean indexing, handling missing values, and reshaping data.
* **NumPy:** Arrays, mathematical operations, and vectorization.

### 3. Exploratory Data Analysis (EDA) & Visualization
* **Matplotlib:** Creating static and foundational plots (line, bar, scatter, histograms).
* **Seaborn:** Statistical data visualization, heatmaps, pair plots, and attractive visual styling.

### 4. Machine Learning Toolkit (Scikit-Learn)
* Data preprocessing, feature scaling, and train-test splitting
* Cross-validation and hyperparameter tuning
* Building ML pipelines

### 5. Machine Learning Models
* **Supervised Learning:**
  * **Regression:** Linear, Multiple, and Polynomial Regression
  * **Classification:** Logistic Regression, Decision Trees, Random Forest, SVM, KNN
* **Unsupervised Learning:**
  * **Clustering:** K-Means, Hierarchical Clustering
  * **Dimensionality Reduction:** Principal Component Analysis (PCA)

## 🛠️ Tech Stack & Tools
* **Language:** Python 3.x
* **Libraries:** Pandas, NumPy, Matplotlib, Seaborn, Scikit-Learn
* **Environment:** Jupyter Notebooks / VS Code
